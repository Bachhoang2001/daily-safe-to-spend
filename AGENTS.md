# Workspace Rules & Conventions

## Git Commit & Push Policy
- **Sau khi hoàn thành mỗi spec (tính năng) hoặc kết thúc phiên làm việc, USER sẽ tự thực hiện các lệnh `git commit` và `git push` code.**
- **Agent TUYỆT ĐỐI KHÔNG tự ý chạy các lệnh `git commit` hoặc `git push` lên repository.**
- Agent chỉ thực hiện kiểm tra trạng thái (`git status`, `git diff`) khi cần xác minh tính toàn vẹn của code.
